---

Use the connected Knowledge MCP tools when available:

- `search_knowledge` for semantic search
- `get_decisions` for architecture trade-offs
- `get_patterns` for reusable implementation patterns
- `get_warnings` for anti-patterns and pitfalls
- `get_methodologies` for step-by-step processes
- `list_sources` for available sources

If MCP tools are unavailable, use the direct HTTP commands documented in `AGENTS.md`.
